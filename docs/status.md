# SimWorld status (detail)

Moved out of `CLAUDE.md` on 2026-10-30 to keep the always-loaded context small. `CLAUDE.md` keeps a short status; this file has the full milestone state, the test baseline and the planned structure. Update it with every milestone or contract change (`/contract-bump`).


"SimWorld" (working name; the repo folder is still `lowpolymap`, the Rust crates are `simworld-core` / `simworld-godot` / `simworld-cli`) is a streamed low-poly OSM city for the SimPlane flight game: a Rust GDExtension (`WorldStreamer`) streams PMTiles around a camera and generates everything; a Godot 4.7 (.NET/C#) addon (`addons/simworld/`) displays it. It started as a spike and is being turned into a reusable library with a test bench. The packaging plan is in `docs/spec-library-packaging.md` (phases P0-P7); this repo has finished P0 (baseline), P1 (core split: Cargo workspace, `World`, `Log`, `Diagnostics`), P2 (contract: `docs/contract.md`, `api_version`), P3 (config: world profile JSON + schema, `configure_world`, `world_profile()`, golden determinism hashes), P4 (host API: geodetic camera input and conversions, `origin_shifted` / `status_changed` signals, `status()`, `attributions()`, `shutdown()`, cache folder lock, several instances) and P5 (addon: `addons/simworld/` with `WorldView`, settings resource, global shader uniforms, `NightLook`, editor plugin, multi-platform `.gdextension`; the test bench consumes it; **not verified: the minimal iOS export**, see "Addon"). Contract version: `api_version` 1.12 (`docs/contract.md`; 1.0 = first breaking change, night windows W2 + W3; 1.1 = street lamps; 1.2 = aircraft warning beacons; 1.3 = R3 ground + `debug_stats()["latency"]`; 1.4 = procedural terrain phase 1, `layers` option; 1.5 = terrain mesh layer (`"t/"` keys), `set_terrain_detail`; 1.6 = `terrain_center` option, `status()["terrain_active"]`; 1.7 = world seed S1: `seed_world` option, `airports()`, `seed_world_info()`, `airport_lights`, ground class 7 + tint, terrain COLOR in a seed world, profile_version 6; 1.8 and 1.9 reserved; 1.10 = Tiles and LOD v2 T3: screen-space-error cover, `set_view`, `set_lod_quality`, profile `lod` section, `bands.r0..r2_edge_m` removed and `bands.r3_edge_m` renamed `bands.max_distance_m`, profile_version 7, `debug_stats` `tau_eff` / `lod_quality` / `lod_edges_m` / view keys; 1.11 = Tiles and LOD v2 T2b/T2c, Rust half: two-level archives (`simworld_levels`, R2 / R3 cut from the overview z11 tile), landmark layer `"l/z/x/y"` (opt-in `layers` value `"landmarks"`), synthetic city as a two-level source, `debug_stats` `data_levels` / `landmarks_*`; Godot half built, see "Addon"; 1.12 = world seed S2-S4: generated cities, `seed_world_info()` city plans, profile `seed.city` / `seed.styles` / `seed.airport.approach`, seed generator 3); crate version 0.5.0 (`CHANGELOG.md`).

Milestones (`docs/spike-streamed-osm-city.md`, "Milestones, acceptance and risks"):

- **M1 Toolchain, M2 Tiles, M3 Buildings, M4 LOD, M5 Ground: done.** Rust modules in `rust/simworld-core/src/`: `fetch` (PMTiles over HTTP range + disk LRU cache: one SQLite file per source, `tiles-{hash}.sqlite`, on its own cache thread; `docs/spec-tile-cache.md`), `mvt`, `geo`, `rings` (quadtree cover R0-R3), `scheduler` (cover, hysteresis, sibling swap, fades), `worker` (tokio + rayon), `mesher`, `ground`, `lights`, `synthetic` (offline city), `latency` (per-band stage latencies of fresh deliveries, `debug_stats()["latency"]`), `world` (`World`: frame, floating origin and re-center, re-delivery pacing, warning rate limit, profiling; mirrors the contract in plain Rust), `diag` (`Log` trait, `Diagnostics`). The only `godot` code is `rust/simworld-godot/src/` (`streamer.rs` type-conversion shell over `World`, `host.rs` mapping `Log` to `godot_print!`/`godot_warn!`/`godot_error!` and `SIMPLANE_PROFILE=1` to `Diagnostics`, `lib.rs` entry).
- **M6 Night: partway.** Built: dithered LOD fades (`poll_fades`, `shaders/lod_dither.gdshaderinc`; at most `fades.max_active` = 4 swaps fade at once, both layers together, the rest swap without a fade), glow/fog/tone map/eye adaptation (`NightRenderController`), light sprites with a `night_factor` (roads do not glow), and an interim C# daylight clock (`TimeOfDay`, `DaylightMenu`; NOAA sun math in C#). **W1 of `docs/spec-night-windows.md` built:** `building_windows.gdshader` (replaces `building_day`): procedural window grid (first from the meter UV, since W3 from window-unit UV), integer hash, `simworld_night_factor`, hard-coded shares and colours, windows under the glow threshold (`emission_level` set from `NightLook.EmissionLevel` through `WorldView.SetEmissionLevel`). **W2 built (Rust):** light profiles `landmark` (6) / `dark` (7) with kind moves, `buildings.overrides` / `dark_states` / `slender_tower` / `min_window_wall_m`, `windows` / `floodlight` profile blocks (profile_version 4), tile attributes `historic`, `man_made`, `windows`, `ruins`, `disused`, `abandoned` (archive rebuilt), no light point for `dark`. **W3 built (Rust half), `api_version` 1.0:** `mesher::emit_polygon` splits each ring into wall runs at corners (> 35°, or > 20° with both edges ≥ 2 × `width_m`; clip seams end a run; rings rotated to their first corner), wall `u` in window columns (`round(len / width_m)` per run, continuing across the rings of a polygon), `v` in whole floors stretched to the wall height; windowless walls (no `windows` block, `windows=no`, wall < `min_window_wall_m`, every R2 wall via `LodParams::windows`) get `u = -1` and `v` in meters; roof / cap UV unchanged. **W3 Godot half built:** `building_windows.gdshader` uses `floor` / `fract(UV)` (no windows on `u < 0` walls, no floor lines on landmark/dark), the facade expects api major 1 and refuses any other (`ExpectedApiMajor` = 1, `LatestKnownMinor` = 7 since api 1.7), bench aids `--cam-yaw` / `--cam-xz`. **W4 built (host, plus one Rust default):** `WorldView` reads `lit_share`, `color` and `floodlight` from `world_profile()` (`WindowProfile`), `SetTime` writes the interpolated hourly shares to both building materials (`TilePool.SetWindowShares`, hour step > 0.01 h), the landmark gets a floodlit base that blooms while windows do not, the window average is weaker / desaturated / cooler and fades to zero between 900 and 2000 m of view depth while the R1 light sprites fade in over the same range (`lights.min_ring` default 2 -> 1 within profile_version 4; `WorldRenderSettings.WindowSpriteBlendStartM/EndM`); `--window-selftest` in the bench. **Street lamps built (api 1.1):** `lights.street` profile block, lamps every 35 m along lit roads (`lights::street_points`), ready-tile keys `street_lights` / `street_light_colors`, drawn by a second sprite MultiMesh per tile in sodium orange at every distance. plus soft light pools on the ground under each lamp (`street_light_pool.gdshader`, the same MultiMesh drawn a second time, fading out by 2.5 km). **Beacons built (api 1.2):** red / green blinking aircraft warning lights on every building with a roof of 60 m or more, placed from geometry only (`lights::beacon_points`, profile `lights.beacons`), ready-tile keys `beacon_lights` / `beacon_light_colors`, host: kind 3 of the points mesh in `light_sprite.gdshader`. **Not built:** `set_clock` / `daylight()` in Rust, a seam-exact window grid, industrial wall lamps.
- **M7 Imagery, M8 Measure: not started.**
- **M10 World seed: S1 built (Rust api 1.7 + Godot half; `docs/spec-world-seed.md` 11c, 11d); S2-S4 built on the Rust side (api 1.12, spec 11f): city plans (hex cells, automatic districts, arterials, radials, airport access; `seed::city`), cached district plans (street lattice per style, lots, buildings with kinds / levels, approach-surface caps), `simworld-cli seed preview`; the Godot `--seed-selftest` S2 / S3-S4 groups built (2026-10-30); S2b / S4a / S4b not built.** `seed_world` option, `airports()`, `seed_world_info()`, water / countryside ground and runway strips in the height function, airport lights; Godot: `WorldView.SeedWorld`, class 7 / tint / terrain class shaders, airport light sprites, runway markings, `SeedTwoCities.tscn`, `--world=` / `--seed-spot=` / `--seed-selftest`. S2b+ (inter-city roads, landmarks, edits, real sources) not started.
- **M9 Terrain: built procedurally (Rust api 1.4-1.6, profile_version 5; Godot side built):** seeded terrain with no data (`simworld-core/src/terrain/`, `docs/spec-terrain.md` design-change note), opt-in via `configure_world` option `layers: ["world", "terrain"]` + `terrain.enabled` (`status()["terrain_active"]` says whether it runs; `terrain_center` keeps the flat zone across reconfigures); bases, foundations, draped ground (water too, `water_snap_m` default 0), lights, cover boxes (the 9 x 9 range; no longer widened by the delivered TIN since api 1.10 G2) and `ground_height_at` use it (0 when off); the terrain mesh layer (Delatin TIN with skirts, `"t/z/x/y"` keys, own quadtree cover with horizon cull) streams next to the vector layer; Godot side `TerrainCover` / `TerrainPool` / `terrain.gdshader` / optional `TerrainCollision` (see "Addon"). Open (review): horizon cull is a no-op at the default relief and the tile / draw-call budgets were measured at amplitude 160 only, skirt sizing across bands. Decided: building bases are not lifted by the drape lift (`docs/spec-terrain.md` 6.2).
